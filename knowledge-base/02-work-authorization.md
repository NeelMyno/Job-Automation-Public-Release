## The work-authorization line on applications

**Default: silence.** Never volunteer sponsorship status in a cover letter or outreach message unless
a form explicitly asks. When a form does ask, the exact wording it uses matters: different phrasings
of "do you need sponsorship" can have different honest answers depending on your situation. The
**only** place the exact mapping lives is `knowledge-base/12-application-answers.md` §3; an agent
should open that file and match the form's literal wording every time, never recall an answer from
memory or from this file.

## Immigration mechanics: confirm with a professional

This file (and this whole repo) is not immigration advice. If your situation is at all complex
(visa transfers, extension timing, sponsorship negotiation), verify anything load-bearing with an
immigration attorney before you rely on it for a real decision.
