# Projects & Portfolio

## Metric ground-truth

**List only numbers you can actually source.** The honesty rule governing this whole file lives in
`07-master-resume.md`'s canonical facts block (its `never:` and `number:` lines are the same rule,
just mechanically enforced there). A project write-up is a fuller version of a résumé bullet, not a
looser one: if a number here would fail the same sourcing test as a résumé claim, it does not belong
here either. The moment a number turns out to be wrong, fix it here too. Never let a project's
write-up drift ahead of what is provably true.
