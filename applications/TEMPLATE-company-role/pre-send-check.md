# Pre-send check — Company · Role Title

Six items. Each must be genuinely done, not just checked, before anything in this dossier ships.
`scripts/verify_claims.py` (rule R8) enforces that this file exists and every item is marked.

- [ ] **FULL-TEXT** — the primary posting was read in full from its real source, not a summary or
  an aggregator's paraphrase.
- [ ] **MEDIA** — every attached image/diagram was actually looked at, because a requirement can
  live only in an image.
- [ ] **NO-ANSWERED-QUESTIONS** — outbound messages don't ask a contact anything their own public
  material already answered.
- [ ] **PERSON** — every named contact's role/identity is grounded in an actually-fetched source,
  not assumed.
- [ ] **COMPANY** — the research traces to real, stored sources.
- [ ] **ABSENCE-CLAIMS** — every "not stated" / "not found" claim names exactly what surface was
  checked, rather than asserting a bare, unscoped absence.
